# Production Environment Variables Setup

This document lists all environment variables needed for production deployment on Render.

## How to Set These in Render

1. Go to your Render service dashboard
2. Click **Environment**
3. Add each variable listed below
4. Click **Save** (triggers rebuild)

## Required Variables

### Node & Security
```
NODE_ENV = production
JWT_SECRET = <auto-generated by Render>
WEBHOOK_TOKEN = <auto-generated by Render>
```

### Supabase (Required)
```
SUPABASE_URL = https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY = eyJhbGc...your-service-role-key...
VITE_SUPABASE_URL = https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY = eyJhbGc...your-anon-key...
```

**Where to find:**
- Go to Supabase Dashboard → Settings → API
- Project URL → SUPABASE_URL
- Service Role Key → SUPABASE_SERVICE_ROLE_KEY (keep secret!)
- Anon Key → VITE_SUPABASE_ANON_KEY

### WhatsApp Server (Baileys)
```
BAILEYS_URL = https://riseflow-wa-xxxxx.onrender.com
BAILEYS_KEY = <shared-api-key-from-baileys-server>
```

**Note:** Deploy WhatsApp server separately (GustavoAgrico/riseflow-wa-server). The API key must match between servers.

### CORS & App URLs (Set after first deploy)
```
CORS_ORIGIN = https://riseflow-app-xxxxx.onrender.com
APP_URL = https://riseflow-app-xxxxx.onrender.com
PAYMENT_RETURN_URL = https://riseflow-app-xxxxx.onrender.com/credits
SERVER_URL = https://riseflow-app-xxxxx.onrender.com
```

### AbacatePay Payment System (Required for Payments)
```
ABACATE_API_KEY = prod_your_abacatepay_api_key
ABACATE_WEBHOOK_SECRET = whsec_your_webhook_secret
```

**Where to find:**
1. Log into [app.abacatepay.com](https://app.abacatepay.com)
2. Settings → API Keys → copy Production API Key
3. Webhooks → create new:
   - URL: https://your-app.onrender.com/api/payments/webhook
   - Copy the Webhook Secret


### Telegram Integration
```
TELEGRAM_BOT_TOKEN = your_telegram_bot_token
TELEGRAM_WEBHOOK_BASE = https://riseflow-app-xxxxx.onrender.com
```

### Meta/Facebook Integration
```
META_APP_ID = your_meta_app_id
META_APP_SECRET = your_meta_app_secret
META_VERIFY_TOKEN = your_meta_verify_token
META_CONFIG_ID = your_config_id
```

### Web Push Notifications
```
VITE_VAPID_PUBLIC_KEY = your_vapid_public_key
VAPID_PUBLIC_KEY = your_vapid_public_key
VAPID_PRIVATE_KEY = your_vapid_private_key
```

Generate with: `npm install -g web-push && web-push generate-vapid-keys`

### Email (SMTP)
```
SMTP_HOST = smtp.gmail.com
SMTP_PORT = 587
SMTP_USER = your_email@gmail.com
SMTP_PASS = your_app_password
```

## Render Environment Hints

- **VITE_*** variables: These are build-time variables (baked into the bundle). Changes require a new build.
- Auto-generated variables: JWT_SECRET and WEBHOOK_TOKEN are auto-generated by Render on first deploy
- Buildargs: The Dockerfile reads VITE_* variables as ARGs during Docker build phase

See `DEPLOYMENT.md` for full deployment guide.
