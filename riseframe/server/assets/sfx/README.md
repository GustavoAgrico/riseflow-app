# Sons da legenda

`tecla-01.wav` … `tecla-08.wav`: batidas de teclado (mono, 44,1 kHz, ~70 ms cada) recortadas
do arquivo de efeito enviado pelo dono do Riseframe. São usadas no estilo de legenda Premium
(uma tecla a cada palavra) e nas palavras com ênfase. O app sorteia entre elas para soar como
digitação. Sem esses arquivos, o servidor sintetiza um clique parecido.
