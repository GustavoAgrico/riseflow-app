# Pacote de efeitos sonoros (entra no site e no app de PC)

Cada subpasta é uma categoria da aba **Efeitos → Sons** do editor; cada arquivo de áudio
(`.mp3`, `.wav`, `.ogg`, `.m4a`, `.aac`, `.flac`) dentro dela vira um som da biblioteca.

- **Adicionar sons:** coloque os arquivos numa subpasta (existente ou nova). Pasta nova vira
  categoria nova (ex.: `risadas/` → "Risadas"). O nome do arquivo vira o nome do som
  (`risada_curta.mp3` → "Risada curta"). Depois é só publicar uma versão nova.
- **Licença:** use só sons livres para uso comercial **sem exigir crédito** (CC0 / domínio
  público) ou sons próprios. Não coloque sons do CapCut, de bancos pagos ou de licença
  "só pessoal".
- `pack.json` traz o nome em português, a categoria e a duração dos sons já incluídos.

Sons incluídos: 186 sons do pacote **uisfx 0.4.0** (npm), áudio dedicado ao domínio público
pela **CC0 1.0** (https://creativecommons.org/publicdomain/zero/1.0/), normalizados para o
mesmo volume.
