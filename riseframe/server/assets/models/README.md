# Modelos de áudio

`voz.rnnn`: modelo RNNoise "somnolent-hogwash" (fala + ruído de gravação) do repositório
[GregorR/rnnoise-models](https://github.com/GregorR/rnnoise-models). O README de lá informa
que os modelos não são obra criativa e não estão sujeitos a direito autoral. É usado pelo
filtro `arnndn` do FFmpeg na opção "Remover ruído: IA (forte, para fala)".
